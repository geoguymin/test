## 조판 원칙: 어절 기준 자간 맞춤

조판본은 본문을 양쪽 정렬하고, 줄은 어절(띄어쓰기 단위)에서만 나눈다. 한 어절이 두 줄로 쪼개지지 않고, 줄마다 남는 폭은 어절 사이 간격으로 고르게 채운다(CSS `text-align: justify; text-justify: inter-word; word-break: keep-all`). 원고 단계에서는 이를 위해 문단 안 강제 줄바꿈 금지, 어절 사이 공백 한 칸, 한글 맞춤법 띄어쓰기, 긴 어절(슬래시 나열 등) 피하기, 공백 정렬 도식 금지를 지켰다. 한글(HWP)로 옮겨 편집할 때는 '문단 모양 → 정렬: 양쪽 정렬', '줄 나눔 기준 → 한글: 어절'로 같은 효과를 낼 수 있다.

## 매 회 구성

- **① 장면 — 질문이 태어나는 순간** — 일상 장면에서 Q0가 튀어나오는 순간까지를 대화와 함께 보여 준다.
- **② 노란 카드: 질문ON 진단** — 질문ON 화면과 같은 모양으로 꼴(F~R)·깊이(표면적 호기심/본질 탐구형/성찰·메타인지형)·블룸(예: 이해하기 · UNDERSTAND) 세 칸, 루브릭 5줄(✔/✕, 질문ON 문구 그대로), '루브릭 충족 n/5'를 보여 준다.
- **③ 질문 쪼개기(초록 카드)** — 쪼개기 전략을 한 줄로 밝힌다(1~4회 꼴별, 5~11회 핵심어별, 12~16회 관점별, 2학기 학생이 직접 쪼개고 서로의 판정을 고침).
- **④ 탐구 일지** — 설문·실험·인터뷰·사고실험·발췌문 읽기 장면.
- **⑤ 질문 사다리** — Q0→Q1→…→파란 카드를 3~5단계 도식으로 정리하고, 단계마다 꼴·깊이·블룸·기술(복합은 M2+M12)·계기·〔바꾼 사람·이름 붙인 사람〕을 한 줄씩 적는다.
- **⑥ 사상가의 목소리** — 사상가 2~4명의 실제 주장을 출처와 함께 소개하고 서로 어디서 부딪히는지 보여 준다.
- **⑦ 파란 카드와 보라 카드** — 파란 카드: 최종 문항, 핵심 개념어 정의(bac_notions의 핵심 개념을 반드시 포함), 문제 제기 2~3문장(이 '왜' 문장이 루브릭 ③을 채움), 논의 방향 2~3갈래.
- **⑧ 논술 작업대** — 이번 회 중점 기술과 짝을 이루는 논술 기술(서론 문제 제기, 개념 구별, 반례 전환 문단, 조건부 결론, 열린 결론 등)을 짧은 예시와 함께 설명한다.
- **⑨ 너의 질문 차례** — 다른 형식의 문항(alt)을 제시하고, 독자가 자기 Q0를 이번 기술로 고쳐 쓴 뒤 질문ON과 같은 체크표(✔/✕, n/5)로 점검하게 한다.
- **⑩ 교사용 노트(부록)** — 수업 연결 방법, 민감 회차의 안전 지침(season_hook의 [집필 지침]), 범위 밖 질문이 나왔을 때의 대응을 적는다.

## 활용 메모

- 휴재 주간: 5월 1주(1학기 중간), 7월 1주(1학기 기말), 10월 3주(2학기 중간), 12월 2주(2학기 기말). 추석(20회)과 수능(26·27회)은 해마다 날짜를 확인해 앞뒤 회와 순서를 바꿀 수 있다.
- 민감 회차(14·26·27·28회)는 ① 첫 줄에 안내문과 도움 창구가 있고, ⑩ 교사용 노트에 지도 지침이 있다.
- 이야기 속 설문·실험 수치는 모두 '(동아리 자체 조사)'로 지어낸 것이다. 실제 연구는 각주로 출처를 밝혔다.
- 발췌문은 저작권이 끝난 원전을 직접 옮겼거나, 저작권이 남은 현대 저작의 요지를 풀어 쓴 것이다. 각 발췌에 '(원문을 직접 옮김)', '(요지를 풀어 옮김)', '(…의 논지를 바탕으로 새로 씀)'을 표시했다.
- 학교 이름은 쓰지 않았다. 등장인물과 장면은 모두 지어낸 것이다.
- 실제 통계(예: 27회 사교육비 조사, 7회 무급 가사노동 가치)는 게재 시점에 최신 발표로 각주를 확인한다.
